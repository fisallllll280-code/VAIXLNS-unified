# VX Repository Command Studio

## Screens

Repository Universe | Architecture Graph | Capability Matrix | Duplicate Detector | Innovation Forge | Interfaces | PR Queue | Proof & Health

## Customer flow

SELECT GOAL -> SELECT REPOSITORIES -> SELECT DOMAIN -> GENERATE PLAN -> REVIEW DIFF -> OPEN PR -> VERIFY -> PROMOTE

## Repository view

Show role, dependencies, capabilities, gaps, lineage, interfaces and proposed innovations.

## Multi-repository graph

Nodes are repositories. Edges represent imports, shared capabilities, canonical references, duplicated functionality or planned integrations.

## Non-destructive default

The studio proposes moves, merges and deprecations. It does not delete or overwrite repositories automatically.
