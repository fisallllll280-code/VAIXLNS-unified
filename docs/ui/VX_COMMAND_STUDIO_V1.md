# VX Command Studio V1

## Main workspace
1. Mission selector
2. Domain selector
3. Multi-mind board
4. Architecture graph
5. Mathematics/physics/computing workspaces
6. Simulation panel
7. Memory Fabric
8. GitHub Federation browser
9. Evidence/Proof panel
10. Runtime/Operations console
11. Innovation Forge

## Multi-mind board
Every agent card shows: role, provider, capabilities, current task, evidence, confidence, conflicts and resource usage.

## Innovation Forge
The Forge shows candidate combinations, why they were generated, which existing capabilities they reuse, simulation status, verification status and lineage.

## Memory Fabric
Users can inspect, pin, invalidate, branch and reuse memory records. Memory changes are recorded as events; silent mutation is forbidden.

## GitHub Federation
Repositories are searchable as engineering sources. The interface distinguishes source code, documentation, tests, examples, dependencies and unverified proposals.

## Runtime
Controls: prepare, simulate, test, authorize, execute, pause, replay, recover, verify.

## Interface generation
The UI itself is mission-aware. Selecting Physics exposes simulation/model panels; Mathematics exposes symbolic/formal panels; Engineering exposes constraints/topology/resource panels; Computing exposes code/build/runtime panels; Invent exposes the Innovation Forge.

## Operating principle
The customer chooses the objective and constraints; VX composes the workspace and delegates to the appropriate minds and tools.
